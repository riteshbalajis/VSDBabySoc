## Soc

A System on a Chip (SoC) is an integrated circuit that combines most or all essential components of a computer or electronic system onto a single microchip.

Unlike older designs where the CPU, GPU, and memory were mounted separately on a board, an SoC integrates all these components into one chip.

## VSD BabySoC

VSD BabySoC is a small RISC-V–based System-on-Chip designed for open-source chip design learning and experimentation.

It contains:

- RVMyth Microprocessor (CPU)
- 8x PLL (Clock Generation)
- 10-bit DAC (Digital-to-Analog Converter)

---

## RISC-V Core (RVMyth)

RVMyth is a compact RV32I RISC-V processor using a simple 5-stage pipeline: Fetch, Decode, Execute, Memory, Write-Back.

It uses a hardcoded instruction memory to run a small program that updates register x17, which is used as the SoC output for DAC waveform generation.

### RVMyth Interface

| Signal Name | Direction | Width | Purpose |
|-------------|-----------|--------|---------|
| OUT         | Output    | 10-bit | Outputs the value of register x17 for the DAC |
| CLK         | Input     | 1-bit  | System clock for the entire pipeline |
| reset       | Input     | 1-bit  | Resets PCs, registers, and memories |

## PLL (avsdpll_1v8)

A Phase-Locked Loop (PLL) produces a stable, controlled clock signal by matching its timing to a reference input. It adjusts continuously to stay synchronized and is commonly used to generate clean, reliable clock frequencies.

### PLL Interface

| Signal Name | Direction | Type | Purpose |
|-------------|-----------|------|---------|
| CLK         | Output    | reg  | Generated PLL output clock |
| VCO_IN      | Input     | wire | External VCO signal input (unused in this model) |
| ENb_CP      | Input     | wire | Charge-pump enable (unused here) |
| ENb_VCO     | Input     | wire | Enables or disables VCO clock generation |
| REF         | Input     | wire | Reference clock for frequency measurement |
| period      | Internal  | real | Stores current output clock period |
| lastedge    | Internal  | real | Timestamp of previous REF rising edge |
| refpd       | Internal  | real | Computed reference clock period |

### Code Explanation

1. **Reference Clock Measurement**  
   On every REF rising edge, the time difference from the previous edge is measured, giving the reference period.

2. **VCO Frequency Adjustment**  
   The PLL sets its oscillation period to one-eighth of the reference period:  
   `period = refpd / 8.0`

3. **Clock Generation Loop**  
   When ENb_VCO is 1, the clock toggles every half-period. When 0, the clock is forced low.

4. **ENb_CP Signal**  
   Present for compatibility with analog models but unused here.

5. **Toggle Assignment Explanation**  
   `CLK <= (CLK === 1'b0);`  
   Toggles the clock: 0 becomes 1, any other value becomes 0.

## DAC (avsddac_3v3)

A Digital-to-Analog Converter (DAC) converts a digital binary value into a corresponding analog voltage, enabling digital systems to interface with analog signals.

### DAC Interface

| Signal | Type | Purpose |
|--------|------|---------|
| OUT    | real output | The analog voltage generated by the DAC |
| D      | 10-bit input | Digital input value to be converted |
| VREFH  | real input   | High reference voltage |
| VREFL  | real input   | Low reference voltage |
| Dext   | wire         | Zero-extended version of D |
| EN     | wire         | DAC enable signal |
| NaN    | real         | Invalid value indicator |

### Code Explanation

The DAC converts a 10-bit value (D) into an analog voltage between VREFL and VREFH.

- D is zero-extended to ensure proper numerical handling.
- Output voltage uses the formula:  
  `OUT = VREFL + (D / 1023) * (VREFH - VREFL)`
- The output updates whenever D, EN, or reference voltages change.
- Invalid reference inputs produce a NaN output to prevent incorrect analog values.

This module acts as a simple behavioral DAC mapping a digital code to an analog voltage.

### Modules inside VSDBabySoC ( VSDBabySoC/src/module/):

![](img/lsmodule.png)

- avsddac.v
Contains the behavioral model of a DAC that converts a 10-bit digital input into an analog voltage using reference levels.

- avsdpll.v
Implements a simplified behavioral PLL model that generates a clock whose frequency tracks the reference input.

- rvmyth.v
The RISC-V processor core (RVMyth), handling instruction fetch, decode, execute, memory, and write-back stages.

- vsdbabysoc.v
Top-level SoC integration file that connects the RVMyth CPU, DAC, PLL, and other modules into a complete system.

- testbench.v
Simulation testbench that drives inputs, monitors outputs, and verifies the behavior of the entire SoC design.

| **4. Source File** | `src/module/testbench.v` | The main Verilog source file used as the entry point for compilation (usually the testbench) |
| **5. Include Paths** | `-I src/include`, `-I src/module` | Adds directories to the search path for \include` files used inside Verilog code and add verilog files inside module |

## Gate-Level Simulation (GLS)

- Gate-Level Simulation (GLS) is the process of simulating a synthesized netlist (after RTL is converted into logic gates) to verify that the design behaves correctly at the gate level.

- GLS is performed to check timing, functional correctness, and logic after synthesis, ensuring the final hardware will work as intended before fabrication.
